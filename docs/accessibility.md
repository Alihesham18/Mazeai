# Accessibility

Target: WCAG 2.2 AA.

Implemented in Phase 1:

- Semantic page structure
- Skip link
- Sticky keyboard-accessible header
- Escape handling for open navigation
- Mobile dialog navigation with scroll locking
- Visible focus states
- AA-oriented dark color tokens
- Reduced-motion CSS guard

Phase 3 forms must include visible labels, inline errors, error summaries, `aria-describedby`, `aria-invalid`, `aria-live`, consent handling, and spam-protection integration points.
